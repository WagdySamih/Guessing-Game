# Guessing Game

A simple mobile guessing game built with React Native and Expo using TypeScript.

## Features

- Simple and fast gameplay
- Smooth UI with Expo
- Modern React Native architecture
- Cross-platform (iOS / Android)
- Lightweight and fast

## Tech Stack

- React Native
- Expo SDK 56
- TypeScript
- React 19
- React Native SVG
- Expo Linear Gradient
- Lucide Icons
